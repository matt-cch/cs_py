# `deploy-git-isolated/archive/` 目录说明

本目录存放 **本 task 已退役或冻结的历史版本**。

## 归档规则

**触发条件**（满足任一）：
- Task 进入长期冻结（6 个月无活跃变更）
- MAJOR 版本升级，旧版本需保留历史
- 人类明确指令「归档此 task」

**命名格式**：
```
archive/<task-name>-v<N>/
```

示例：`archive/deploy-git-isolated-v1/`

**归档内容**：
- 完整复制原 task 根目录所有文件（保留历史真源）
- 归档目录内的 `README.md` 顶部标注 `**已归档**` + 归档日期 + 替代版本路径
